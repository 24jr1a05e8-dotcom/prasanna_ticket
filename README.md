# Prasanna Chowdary - Movie Ticket Booking System 🎬

A beginner-friendly Python + Streamlit project based on Project 2 of the provided Python + Streamlit Project Challenge.

## Features
- Select a movie
- Choose number of tickets
- Select ticket category: Standard, Premium, VIP
- Select show time
- Select seat preference
- Calculate ticket price
- Calculate booking fee
- Display booking summary
- Generate booking ID
- Download booking summary
- Colorful responsive UI
- Animated header and hero section
- No database used

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project requirement
This project uses Python + Streamlit and stores everything in variables/dictionaries. No database is used.
